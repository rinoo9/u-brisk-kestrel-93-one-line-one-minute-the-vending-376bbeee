# One Line, One Minute: The Vending Machine Pickup Line Contest

A one-line vending machine pickup line entry for the make.fun bounty "One Line, One Minute: The Vending Machine Pickup Line Contest". The program `main.py` writes a single pickup line to `/output/entry.txt` — no exact change needed, press B4, and the machine drops itself, the sweetest snack in the row, straight into your hands.

> No exact change needed — press B4 and I'll drop myself, the sweetest snack in this row, straight into your hands.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
